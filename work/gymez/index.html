Gymez

Mohamed Ezz·1 min read2 live apisgithub ↗live ↗

A full-stack fitness web app that personalizes a user's workout and nutrition based on their own body data and goals, instead of giving everyone the same generic plan.

  • Next.js
  • Supabase
  • Exercise Image API
  • Barcode API
In this essayProblemApproachWhat I builtTechnologies

Problem

People starting a fitness journey usually get one-size-fits-all plans that ignore their current condition, goals and lifestyle.

Approach

Built as a rule-based system with no ML model: user data drives the workout and nutrition logic, with weight tracking and progress charts.

What I built

User onboarding, weight tracking, personalized workout plans, a nutrition system and progress charts.

Technologies

Next.js for the full-stack app, Supabase as the database, a third-party API for exercise images and a barcode API for food lookup.
