Selected Projects

01 / GYMEZ

Gymez

A full-stack fitness web app that personalizes a user's workout and nutrition based on their own body data and goals, instead of giving everyone the same generic plan.

Next.js Supabase Exercise Image API Barcode API
RoleFull-stack developer
GitHub Live Demo
Case study+
Problem

People starting a fitness journey usually get one-size-fits-all plans that ignore their current condition, goals, and lifestyle.

Approach

Built as a rule-based system (no ML model): user data drives personalized workout and nutrition logic, with weight tracking and progress charts.

Stack

Next.js for the full-stack app, Supabase as the database, plus a third-party API for exercise images and a barcode API for food lookup.

Key features

User onboarding, weight tracking, personalized workout plans, nutrition/diet system, and visual progress charts.
