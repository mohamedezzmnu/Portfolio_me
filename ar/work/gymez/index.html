Gymez

تطبيق ويب متكامل للياقة البدنية بيخصص خطة التمرين والتغذية على حسب بيانات جسم المستخدم وأهدافه، بدل خطة عامة للجميع.

  • Next.js
  • Supabase
  • Exercise Image API
  • Barcode API

المشكلة

الناس اللي بتبدأ رحلة لياقة بدنية بتاخد غالبًا خطط عامة مش بتراعي حالتهم وأهدافهم ونمط حياتهم.

المنهج

اتبنى بمنطق قواعد (بدون موديل ML): بيانات المستخدم بتوجّه منطق التمرين والتغذية، مع متابعة الوزن ورسومات للتقدم.

اللي بنيته

تسجيل بيانات المستخدم، متابعة الوزن، خطط تمرين مخصصة، نظام غذائي، ورسومات متابعة.

التقنيات

Next.js للتطبيق الكامل، Supabase كقاعدة بيانات، و API خارجي لصور التمارين و API للباركود.

ملاحظات هندسية

التنبؤ بالودائع البنكيةبتدخل بيانات بروفايل العميل وتفاصيل المكالمة، والموديل بيقدّر احتمالية اشتراكه في وديعة لأجل.
